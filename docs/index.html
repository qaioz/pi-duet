duet

Pair your coding agent with a friend's. Ask yours to ask theirs: “ask nika's agent to run the tests and send me the failures”. Works with pi, Claude Code and Codex, in any mix. No accounts, nothing to host.

1. Start a room

You get an invite link. Send it to the other developer by any channel you like.

Invite link

Whoever has this link can make your agent run commands on your machine. Share it only with someone you trust. duet adds no permission prompts of its own: your agent's own permission mode decides what the other agent's requests can do.

4. Talk to your agent

Just ask it: “ask nika's agent what it thinks of this plan”, “ask nika's agent to run the tests and send me the failures”. The request lands in the other agent's session, it does the work with its own tools, and the answer comes back into yours.

How it works

The room code lives only in the part of the link after #, which browsers never send to a server. Messages travel through ntfy.sh, a free public relay, on a topic named after a hash of the room code. Claude Code and Codex join through a small MCP server run with npx (needs Node 20 or newer); pi through its own extension. Source, limits and safety notes: github.com/qaioz/pi-duet.
