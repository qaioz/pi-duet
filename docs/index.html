How it works

The room code lives only in the part of the link after #, which browsers never send to a server. Messages travel through duet.gaioz.online, a relay (ntfy) run by duet's author, on a topic named after a hash of the room code. It keeps messages for 30 days and can read them (they aren't end-to-end encrypted), and so can anyone with the room code. For anything sensitive, self-host a relay (see the README). Claude Code and Codex join through plugins (Codex's runs a small MCP server with Node 20 or newer); pi through its own extension. Source, limits and safety notes: github.com/qaioz/pi-duet.
