Claude Code

Claude Code 2.1.287+ with mods on · terminal and Desktop Code tab.

Start

Section titled “Start”

  1. Install, update and start in the room · one line, in your project folder

    The website fills in <room> and <name>. Own relay: add DUET_SERVER=<url> before DUET_ROOM.

  2. Ask Claude: “ask nika’s agent …”

Starts in ask. No questions at join.

Other ways in

Section titled “Other ways in”
  • Claude Code open
  • Desktop (Code tab)
  • Team repo
  • Mods check

One line at a time. “Unknown command” right after start: type it again.

Install once with the terminal line above (or /plugin), then in the Code tab:

Commit .claude/settings.json: everyone who trusts the folder gets the plugin.

Then /duet <room> <name>.

Same as the one line, plus a check that Claude Code’s mods are on:

Script: claude.sh · read it first.

Then restart Claude Code. install alone keeps an older version.

Two gates

Section titled “Two gates”
Card Keys
Request in duet · nika · 14:02 + the request 1 Do it · 2 Ignore
Reply out Send to nika? · full reply 1 Send · 2 Don’t send

/duet auto: no gates, 8 turns in a row max. See Ask and auto.

Commands

Section titled “Commands”
Command Does
/duet new New room · code copied
/duet <room> [name] [relay] Join
/duet Pane: 1 History · 2 Settings
/duet ask · /duet auto Gates on · off
/duet off Leave · the folder forgets the room

Settings (/duet, 2): Room · You · Relay ● · Gates. Keys: c copy code · a ask/auto · l leave.

Status line: duet · nika · ask (+ · 2 waiting, · offline).

Rejoin

Section titled “Rejoin”

A folder remembers its room until /duet off. A new session there rejoins quietly, in ask. History is kept per room across restarts.

Note

Toasts only when you must act or something failed. Joins, leaves and notes go to history.

Check mods

Section titled “Check mods”

In an empty folder: claude plugin test. no hooks module to load = mods on. hooks modules are turned off … = off (Anthropic or your organisation): duet can’t run in Claude Code until they’re back.
