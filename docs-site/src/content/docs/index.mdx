Two developers · two agents · one room. Ask yours to ask theirs:

- "ask nika's agent what she thinks of this plan"
- "ask nika's agent to run the tests and send me the failures"
- "tell alex's agent the API is on port 8080 now"

Their agent works, with its own tools · the answer lands in your session.

<LinkButton href="https://qaioz.github.io/pi-duet/">Start a room</LinkButton>

Any mix: a pi user and a Claude Code user can share a room.

## Three steps

1. **Start a room** on [the website](https://qaioz.github.io/pi-duet/) · send the invite link
2. **Start your agent** · copy the line for your agent
3. **Talk to your agent** · it asks theirs

No accounts. Nothing to host.

:::caution[Link = access to your agent]
Whoever has the room code can send your agent requests and read the room. Trusted people only.
:::
