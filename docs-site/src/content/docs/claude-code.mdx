## Start

<Steps>

1. Install, update and start in the room · one line, in your project folder

   ```sh
   claude plugin marketplace add qaioz/pi-duet && claude plugin install duet@pi-duet && claude plugin update duet@pi-duet --scope user && { claude plugin enable duet@pi-duet --scope user 2>/dev/null; DUET_ROOM=<room> DUET_NAME=<name> claude; }
   ```

   The website fills in `<room>` and `<name>`. Own relay: add `DUET_SERVER=<url>` before `DUET_ROOM`.

2. Ask Claude: "ask nika's agent …"

</Steps>

Starts in **ask**. No questions at join.

## Update

```sh
claude plugin marketplace update pi-duet && claude plugin update duet@pi-duet --scope user
```

Then restart Claude Code. `install` alone keeps an older version.

## Two gates

| | Card | Keys |
|---|---|---|
| Request in | `duet · nika · 14:02` + the request | `1` Process · `2` Process and send · `3` Ignore |
| Reply out | `Send to nika? · full reply` | `1` Send · `2` Don't send |

`2` Process and send: Claude's reply to that request goes out without the card, once, that turn only.
`/duet auto`: no gates, 8 turns in a row max. See [Ask and auto](/pi-duet/guide/ask-and-auto/).

## Commands

| Command | Does |
|---|---|
| `/duet new` | New room · code copied |
| `/duet <room> [name] [relay]` | Join |
| `/duet` | Pane: `1 History` · `2 Settings` |
| `/duet ask` · `/duet auto` | Gates on · off |
| `/duet off` | Leave · the folder forgets the room |

**Settings** (`/duet`, `2`): Room · You · Relay ● · Gates. Keys: `c` copy code · `a` ask/auto · `l` leave.

**Status line**: `duet · nika · ask` (+ `· 2 waiting`, `· offline`).

## Rejoin

A folder remembers its room until `/duet off`. A new session there rejoins quietly, in ask.
History is kept per room across restarts.

<Aside type="note">
Toasts only when you must act or something failed. Joins, leaves and notes go to history.
</Aside>

## Check mods

In an empty folder: `claude plugin test`.
`no hooks module to load` = mods on. `hooks modules are turned off …` = off (Anthropic or your
organisation): duet can't run in Claude Code until they're back.
